# Secuencia recomendada de desarrollo

## Etapa 1 — Definición

1. Validar módulos y pantallas mediante el prototipo.
2. Definir actores, casos de uso y reglas de aprobación.
3. Aprobar la matriz de roles y permisos.
4. Elaborar el modelo entidad–relación.

## Etapa 2 — Base técnica

1. Crear el proyecto Next.js con TypeScript.
2. Crear el repositorio y la estrategia de ramas en GitHub.
3. Configurar Supabase, variables de entorno y migraciones.
4. Implementar autenticación y perfiles.
5. Implementar roles, permisos y políticas RLS.

## Etapa 3 — Módulos centrales

1. Áreas, usuarios y proyectos.
2. Tareas, responsables, comentarios y evidencias.
3. Materiales, solicitudes y movimientos de inventario.
4. Aprobaciones y trazabilidad.
5. Panel de avances y reportes.

## Etapa 4 — Integraciones

1. Archivos privados en Supabase Storage.
2. Correos transaccionales con Resend.
3. Diagramas de actividades.
4. Exportaciones PDF y CSV.

## Etapa 5 — Calidad y entrega

1. Pruebas de permisos y flujos críticos.
2. Revisión responsive y de accesibilidad.
3. Despliegues de prueba desde GitHub a Vercel.
4. Configuración del dominio y DNS.
5. Pruebas de aceptación y publicación.
